# Course Management System

A simple Course Management System built using Python and file handling.

## Features

* Add Course
* View Courses
* Search Course
* Update Course
* Delete Course

## Technologies Used

* Python
* Object-Oriented Programming (OOP)
* File Handling
* Loops and Conditions
* Data Management

## File Structure

```text
coursems.txt
```

Stores course information in the following format:

```text
Course ID, Course Name, Trainer Name, Duration
```

## How to Run

1. Install Python.
2. Save the program file.
3. Run the program:

```bash
python course_management_system.py
```

4. Use the menu options to manage course records.

## Learning Outcomes

This project helps in understanding:

* Classes and Objects
* File Handling
* CRUD Operations
* Search and Update Logic
* Menu-Driven Programs
